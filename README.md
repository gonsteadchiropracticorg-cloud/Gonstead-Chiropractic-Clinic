# Gonstead Chiropractic

A comprehensive chiropractic clinic management system built with Next.js.

## Overview

This is a professional website and management system for a Gonstead chiropractic clinic. It includes patient management, appointment booking, educational resources, and administrative tools.

## Features

- Patient appointment booking system
- Educational resources and guides
- Admin dashboard for clinic management
- Money record and management system
- Professional and responsive design

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000) in your browser
